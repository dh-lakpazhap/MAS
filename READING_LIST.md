# Личная подборка

## Установка

Заменить `streamlit_app.py` в корне проекта и добавить рядом `reading_list.py`. Дополнительные зависимости не требуются. Почтовый архив устанавливать не требуется. Параметр `send_email: false` в `config.yaml` остаётся выключенным.

Запуск:

```powershell
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

## Использование

- «Сохранить» в карточке добавляет статью во вкладку «Моя подборка».
- «Просмотрено» устанавливается пользователем независимо от сохранения.
- Переход по ссылке не устанавливает отметку автоматически.
- «Скрывать отмеченные как просмотренные» исключает такие записи из результатов поиска.
- В подборке доступны сохранённые статьи, просмотренные и все отметки. Флажки можно снять.
- Кнопка скачивания создаёт JSON со статьями и отметками. Загрузка объединяет его с текущей подборкой.

В web-поиске автоматическая запись найденных идентификаторов в общую `history.json` и её использование отключены. Отдельный планировщик сохраняет прежнее поведение; файл `history.json` не используется как личная история чтения посетителя.

## Хранение

Подборка хранится в `st.session_state`, отдельно для каждого сеанса. Это не постоянный личный кабинет. При новом сеансе, перезагрузке вкладки или перезапуске сервера она может исчезнуть. Для сохранения между сеансами используется скачивание JSON и последующая загрузка. Между устройствами данные автоматически не синхронизируются.

Идентичность записи определяется источником и идентификатором. Одна статья в разных базах пока имеет независимые отметки.

Почтовый интерфейс и старое раскрытие «Показать подробности» удалены. Схема читается из `diagr/agents.html`.
