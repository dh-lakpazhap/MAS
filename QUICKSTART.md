# Установка и запуск

## Требования

- Python 3.12.
- Доступ к интернету для запросов к источникам и первоначальной загрузки данных NLTK.
- Для режимов LLM — доступный OpenAI-совместимый API и модель.

Все команды выполняются из корня репозитория, содержащего `streamlit_app.py`.

## Windows / PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m nltk.downloader punkt_tab
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

## Linux / macOS

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m nltk.downloader punkt_tab
.venv/bin/python -m streamlit run streamlit_app.py
```

Локальный адрес: `http://localhost:8501`. Остановка сервера: `Ctrl+C`.

## Конфигурация

Основные поля `config.yaml`:

```yaml
topics:
  - "machine learning"
sources:
  - "europepmc"
  - "semantic_scholar"
summarizer: sumy
send_email: false
check_interval_seconds: 3600
history_size: 1000
```

Допустимые источники: `archive`, `arxiv`, `pubmed`, `europepmc`, `semantic_scholar`. Настройки интерфейса переопределяют значения по умолчанию в пределах сеанса.

Sumy и режим проверки по словам работают без LLM и API-ключа языковой модели.

## Подключение модели

На вкладке «Провайдеры» задаются провайдер, адрес API, название доступной модели и способ получения ключа. Для Ollama стандартный локальный адрес — `http://localhost:11434/v1`; модель должна быть установлена на сервере Ollama.

Ключ вводится в поле «Ключ для этого сеанса» либо задаётся переменной окружения. В поле `api_key_env` указывается имя переменной, например `OPENAI_API_KEY`.

Пример установки переменной в PowerShell:

```powershell
$env:OPENAI_API_KEY = "<API_KEY>"
```

Необязательный ключ источника Semantic Scholar:

```powershell
$env:SEMANTIC_SCHOLAR_API_KEY = "<API_KEY>"
```

В режиме «По смыслу — LLM» модель проверяет название и аннотацию. Вызовы внешнего API могут тарифицироваться. Ключ передаётся выбранному endpoint; адрес должен соответствовать доверенному провайдеру.

## Развёртывание

Приложение совместимо со Streamlit Community Cloud. Параметры развёртывания:

| Параметр | Значение |
| --- | --- |
| Репозиторий и ветка | Репозиторий приложения и ветка развёртывания |
| Main file path | `streamlit_app.py` |
| Python | `3.12` |
| Зависимости | `requirements.txt` в корне |

При необходимости серверные ключи задаются в Settings → Secrets на верхнем уровне TOML:

```toml
OPENAI_API_KEY = "<API_KEY>"
SEMANTIC_SCHOLAR_API_KEY = "<API_KEY>"
```

`localhost` в облачном развёртывании относится к облачному серверу. Для удалённой LLM требуется доступный этому серверу API.

Изменения в подключённой ветке GitHub автоматически обновляют приложение. Файлы истории и журнала на сервере не являются долговечным хранилищем. Фоновый планировщик требует отдельного процесса.

## Проверка работы

1. Выбрать один источник, тему, диапазон дат и небольшой лимит записей.
2. Выполнить поиск в режиме «По словам» с Sumy.
3. Проверить ссылки, темы и резюме в результатах.
4. Проверить второй источник и совместный поиск.
5. При наличии модели проверить режим LLM и объяснение оценки.
6. Для публичного развёртывания повторить поиск по публичной ссылке без авторизации владельца.

## Диагностика

| Ошибка | Проверка |
| --- | --- |
| Не найден `punkt_tab` | Загрузить ресурс NLTK командой из раздела установки |
| HTTP 429 | Снизить частоту запросов и повторить позже |
| LLM недоступна | Проверить адрес API, доступность модели и ключ |
| Некорректный ответ проверки | Повторить запрос; модель должна поддерживать возврат JSON по инструкции |
| Пустая выдача | Проверить темы, период, источники и пропуск истории |

Описание архитектуры и ограничений — в [README.md](README.md).
